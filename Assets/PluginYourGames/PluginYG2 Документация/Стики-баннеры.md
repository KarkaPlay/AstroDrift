# Стики-баннеры

> ❗ • Модуль предназначен для отключения или включения отображение блока баннерной рекламы;  
> • Даже без этого модуля блок баннерной рекламы будет включен по умолчанию;  
> • Если вам не нужен функционал отключения или включения его отображения, то не импортируйте данный модуль. В ином случае, чтобы использовать нижеописанный API, необходимо импортировать модуль StickyAdv.

## В каком случае Стики-баннеры НЕ отображаются

> ❗ 1. Размер экрана на ПК слишком маленький;  
> 2. Включён полноэкранный режим;  
> 3. Sticky-баннеры деактивированы в консоли игры;  
> 4. Вы используете API для скрытия баннеров.

## Использование в коде

Для показа или скрытия блока баннерной рекламы используйте следующий метод:

```csharp
YG2.StickyAdActivity(bool activity);
```
