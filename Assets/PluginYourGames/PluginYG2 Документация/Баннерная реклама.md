# Баннерная реклама

**Рекламное объявление на экране снизу, сверху, слева или справа**

> ❗ Данный модуль не предназначен для платформы Яндекс Игры. Для ЯИ смотрите раздел Sticky-Баннеры

- Необходимо импортировать [модуль](/doc/#Модульная_система "Модульная система") BannerAdv.
- Вызывать рекламу можно без написания кода через компонент [EventsYG2](/doc/#EventsYG2_компонент/).

Баннер предназначен для отображения на Android и IOS платформах. Он является агрегатором для реализации API других модулей рекламной сети, таких как [Appodeal](/appodeal "Документация Appodeal") или Яндекс Реклама в мобильных приложениях (модуль в разработке). (Такие модули размещаются на [Boosty](https://boosty.to/maximalist).)

# API

`YG2.SetBannerPosition(YG2.BannerPosition.Bottom)` — перед тем как вызвать метод для открытия баннера, сначала установите значение, которое определяет его расположение на экране. По умолчанию баннер появляется в верхней части.

`YG2.LoadBanner()` — загрузить баннер в кеш. Не для всех платформ это обязательный метод. Смотрите документацию модуля рекламной сети, который используете.

`YG2.ShowBanner()` — показать баннер.

`YG2.HideBanner()` — скрыть баннер.

`YG2.DestroyBanner()` — удалить баннер из кеша. Также, не для всех рекламных сетей данный метод необходимо выполнять.

# Симуляция в Unity Editor

В настройках **Plugin YG** вы найдёте раздел **Banner Adv**, в котором можно задать размер высоты баннера в пикселях и цвет панели, которая будет симулировать объявление. Да, в эдиторе есть симуляция отображения баннера, при желании её можно отключить в тех же настройках.  
Размер баннера может быть разный в зависимости от используемой рекламной сети. Настраивайте интерфейс в вашей игре в зависимости от того, какой рекламный баннер будет отображаться в билде приложения.
