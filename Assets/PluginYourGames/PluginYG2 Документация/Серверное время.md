# Серверное время

**Необходимо импортировать модуль ServerTime.**

С помощью серверного времени вы можете сделать ежедневную награду за посещение игры, или что то похожее.  
Метод `YG2.ServerTime()` возвращает значение типа `long` серверного времени.

> ❗ Серверное время возвращается в миллисекундах.

Для симуляции в Unity Editor значение серверного времени используется из поля **Server Time** в настройках модуля:

# Мультиплатформенность

Яндекс Игры предоставляют возможность получить время со своего сервера, и PluginYG берёт эти данные.

В большинстве случаев другие платформы не предоставляют API для серверного времени. Плагин имеет стандартную реализацию для получения ServerTime. Это значит, что на любой платформе которая не предоставляет API, будет использоваться следующий код плагина:

```csharp
DateTimeOffset.UtcNow.ToUnixTimeMilliseconds();
```
