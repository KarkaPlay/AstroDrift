# Яндекс Реклама в мобильных приложениях

Для модуля рекламной медиации необходимо установить [Plugin Your Games 2.0](https://assetstore.unity.com/packages/tools/integration/plugin-your-games-2-0-302343).  
Обязательные разделы документации к изучению: [Начало работы](/doc/ "Начало работы") и [Платформы](/platform/ "Платформы").

Получить модуль рекламной медиации можно на [Boosty](https://boosty.to/maximalist).

# Описание Yandex Mobile Ads

[Yandex Mobile Ads](https://ads.yandex.com/helpcenter/ru/dev/unity/quick-start-mm "Yandex Mobile Ads") — это SDK для подключения рекламной сети РСЯ к мобильному приложению на Android или IOS. Более того, Yandex Mobile Ads является медиацией. Это значит, что к игре можно подключить и другие рекламные сети. Платформа автоматически управляет различными рекламными сетями, такими как Google AdMob или Unity Ads и другими. Вы можете подключить к своей игре все самые популярные рекламные сети, и умный водопад будет подбирать объявление от наиболее выгодной рекламной сети в момент загрузки баннера. Благодаря медиации и водопаду вы можете увеличить доход и охватить больше регионов для показа рекламных объявлений.

SDK позволяет использовать в приложении такие виды рекламы, как: межстраничные объявления, видео за вознаграждение, баннеры. С помощью алгоритмов аукциона в реальном времени выбирается наиболее выгодное объявление для показа пользователю.

Реклама будет работать в Google Play, Ru Store и на всех остальных мобильных сторах. Чтобы настроить модуль плагина вам нужно только лишь вставить ключ приложения в соответствующее поле. Остальное — это установить сам SDK Yandex Mobile Ads, установить пакет EDM и настроить проект в соответствии с официальной документацией. Ниже вы сможете найти короткое разъяснение, как это сделать!

Чтобы [подключить различные рекламные сети](https://ads.yandex.com/helpcenter/ru/monetization/yandex-mediation/setup "подключить различные рекламные сети"), кроме РСЯ, необходимо зарегистрировать аккаунты соответствующих сетей и заполнить идентификаторы сетей в кабинете РСЯ. Выплаты будут производиться отдельно от каждой подключенной сети.

Если вы инди-разработчик, вам может подойти вариант подключения одной дополнительной сети, например Unity Ads. Выплаты можно получить на счёт, который поддерживает SWIFT и IBAN переводы. У пользователей из СНГ регионов будут, скорее всего, открываться баннеры от РСЯ, а другие пользователи увидят объявления от Unity Ads.

# Помощь в установке SDK Yandex Mobile Ads

Помимо прочтения этой документации, также ознакомьтесь с [официальной документацией Яндекса для мобильной рекламы](https://ads.yandex.com/helpcenter/ru/dev/unity/quick-start-mm "Yandex Mobile Ads"), в которой вы найдёте подробную информацию, в том числе видео по настройке SDK и подключении всех сетей. Также в первоисточнике может быть актуальная и важная информация, которой еще нет здесь.

Чтобы не наткнуться на ошибку во время импорта необходимых пакетов, проверьте через Unity Package Manager не установлен ли в вашем проекте пакет **Advertisement/Advertisement Legacy Package Manager**. Если установлен — удалите.

Для работы модуля **Yandex Mobile Ads** необходимо установить:

- **Модули для платформы Android и IOS** — устанавливаются в Unity Hub для Unity Editor, который вы используете. Даже если вы не портируете игру на IOS, установите модуль, без него в проекте появятся ошибки.
- **External Dependency Manager for Unity (EDM)** — это инструмент для Unity, который управляет зависимостями плагинов и автоматически загружает нужные библиотеки для Android и IOS.
- **Yandex Mobile Ads plugin for Unity** — SDK Яндекс рекламы для мобильных приложений.

Далее мы рассмотрим два варианта установки EDM и SDK Яндекса:

1. [Ручная установка](#ручная-установка "Ручная установка")
2. [Установка через OpenWeb](#установка-через-openweb "Установка через OpenWeb")

> ❗ Модуль плагина Yandex Mobile Ads использует API SDK Yandex Mobile Ads for Unity версии 8. SDK Яндекса должен будет подходить любой восьмой версии (8.x). Версии старше (например версия 7.x), модуль плагина больше не поддерживает.

## Ручная установка

Установите **EDM** именно **.tgz** формата последней версии, [перейдя по данной ссылке](https://developers.google.com/unity/archive?hl=ru#external_dependency_manager_for_unity). Пакет **.tgz** устанавливается через **Unity Package Manager** (нажмите на + и выберите опцию **Install package from tarball…**).

Установите **SDK Yandex Mobile Ads** с Github. Для этого перейдите к списку [Releases](https://github.com/yandexmobile/yandex-ads-unity-plugin/releases), выберите версию и скачайте пакет с названием yandex-mobileads-lite.

Пакет yandex-mobileads-lite содержит рекламную сеть Яндекса и она будет работать по умолчанию. Если вы хотите подключить и другие медиации, импортируйте соответствующие пакеты. Также необходимо зарегистрироваться на сервисе рекламной сети, которую планируете подключать, скопировать необходимые ID и заполнить их в кабинете РСЯ.

## Настройка зависимостей

Перейдя в Unity, скорее всего EDM предложит вам установить зависимости, соглашайтесь. Если вы не увидели такого окна, вы можете запросить обновление вручную. В верхнем меню Unity нажмите **Assets → External Dependency Manager → Android Resolver → Force Resolve**.

В процессе загрузки зависимостей есть вероятность, что она не закончится успехом. Этому может быть много причин, и все решения описать здесь не получится. В случае, если есть проблемы, можем посоветовать:

- Смотреть лог из окна загрузки зависимостей.
- Создать новый проект (или чистить все возможные кеши старого проекта)
- Ищите рабочие комбинации версий всех зависимостей: Unity, EDM, SDK Яндекса, JDK.

Проверьте, чтобы в настройках **Editor → Project Settings → Player → Publishing Settings** были активны параметры **Custom Main Gradle Template** и **Custom Gradle Properties Template**.

При подключении сети **Google AdMob** необходимо создать Custom Main Manifest [следуя документации РСЯ](https://ads.yandex.com/helpcenter/ru/dev/unity/admob "следуя документации РСЯ").  
При использовании **mobileads-mediation** или при импорте отдельного адаптера **Google AdMob** необходимо заполнить идентификатор сети, иначе могут быть различные проблемы!

Чтобы быстро и удобно собирать билды на Android, рекомендую обратить внимание на мой инструмент [Android Wi-Fi Connect (ADB Build)](/adb-connect "Android Wi-Fi EasyConnect (ADB Build)")

После импорта и настройки EDM и SDK Яндекса, установите модуль платформы Yandex Mobile Ads от PluginYG и следуйте инструкции ниже.

# Настройки модуля

В РСЯ создайте приложение и необходимые рекламные блоки для него. ID рекламных блоков вставьте в соответствующие поля в настройках платформы:

Изображение: настройки платформы Yandex Mobile Ads

`Show First Adv` — реклама при первом запуске игры (необходимо создать блок вида «**Реклама при открытии**» и вставить его ID в поле `Yandex Mob App Open Ad ID`).  
`Save Cloud` и `Save Local` — если один из параметров сохранения будет активирован, то модули сохранений будут работать и сохранять данные в PlayerPrefs на мобильных устройствах.  
`Auto Pause Game` — можно выключить, потому что SDK Яндекса имеет собственную реализацию отключения звука и остановки игры во время просмотра рекламы.  
`Archiving Build` — для мобильных приложений архивация билда не требуется.

`Yandex Mob Ads Testing Mode` — оставьте эту опцию включённой на время разработки и тестирования. Перед релизом уберите эту галочку.  
`Yandex Mob Auto Load Ads` — плагин сам будет загружать рекламный блок перед показом рекламы при выполнении метода вызова рекламы.  
`Yandex Mob Inter Ad ID` — ID блока межстраничной рекламы.  
`Yandex Mob Reward Ad ID` — ID блока рекламы за вознаграждение.  
`Yandex Mob Banner Ad ID` — ID блока баннерной рекламы.  
`Yandex Mob App Open Ad Enable` — реклама при открытии приложения после того, как оно было скрыто. При открытии приложения показывается реклама, которую легко закрыть. (Необходимо создать блок вида «**Реклама при открытии**» и вставить его ID в поле `Yandex Mob App Open Ad ID`).  
`Yandex Mob App Open Ad ID` — ID блока рекламы при открытии приложения.

В SDK Яндекса, перед показом рекламы межстраничной и за вознаграждение необходимо выполнять метод загрузки объявления. По умолчанию в настройках платформы плагина включена опция `Yandex Mob App Open Ad Enable`, при которой вам не потребуется вручную вызывать метод загрузки рекламы.  
Но всё же, вы можете заранее подготавливать рекламное объявление, если вы знаете, что в игре скоро должна быть показана реклама. Для этого используйте методы загрузки:

```csharp
YG2.optionalPlatform.LoadInterAdv()
YG2.optionalPlatform.LoadRewardedAdv()
```

При этом не обязательно выключать опцию `Yandex Mob App Open Ad Enable`. Она спасёт, если после выполнения метода загрузки, рекламный блок не успеет загрузиться, а метод вызова рекламы уже выполняется. В таком случае, при вызове рекламы, если баннер ещё не был загружен, то загрузка будет ожидаться дальше, а после загрузки реклама будет показана.  
При выполнении метода загрузки рекламы, если блок уже загружен, новый блок не будет запрашиваться, а будет использован тот что в кеше.

События для подписки на успешное завершение загрузки рекламного блока:  
`YG2.optionalPlatform.onLoadedInterAdv`  
`YG2.optionalPlatform.onLoadedRewardedAdv`

Также есть события клика по рекламе:  
`YG2.optionalPlatform.onClickedInterAdv`  
`YG2.optionalPlatform.onClickedRewardedAdv`

Подробнее о опциональных методах и событиях в разделе [Платформы](/platform/ "Платформы").

Для использования рекламного баннера требуется импортировать модуль [BannerAdv](/banner "BannerAdv").  
Этот модуль позволяет отображать рекламный баннер на экране снизу, сверху, слева или справа. Необходимо выполнить метод для открытия баннера с передачей параметра, который указывает в какой части экрана расположить объявление. Хорошо работает расположение баннера только сверху и снизу для данной платформы. Метод загрузки баннера можно не использовать, он ни на что не влияет для модуля сети Яндекса. Методы удаления и скрытия баннера выполняют одну и ту же функцию — баннер исчезает. Используйте любой из методов.

Подробнее о том, [Какие модули поддерживает та или иная платформа](https://max-games.ru/plugin-yg/doc/platform/#Какие_модули_поддерживает_та_или_иная_платформа "Какие модули поддерживает та или иная платформа")

# Конфиденциальность пользователя

В документации Яндекса, обратите внимание на раздел документации «Конфиденциальность пользователя», а именно на [GDPR](https://ads.yandex.com/helpcenter/ru/dev/unity/gdpr "GDPR") и [COPPA](https://ads.yandex.com/helpcenter/ru/dev/unity/coppa "COPPA").  
По правилам, при первом запуске приложения вы должны уведомить пользователя о том, что приложение может собирать персональные данные для показа рекламы. Также необходимо дать возможность отказаться от передачи данных.

Пример уведомления:

> **Политика конфиденциальности**
>
> Мы используем данные для показа рекламы и улучшения приложения.  
> Вы можете принять или отклонить использование персонализированной рекламы.
>
> Подробнее — в политике конфиденциальности (ссылка)
>
> Укажите возраст:  
> ○ Мне меньше 13 лет  
> ○ Мне 13 лет или больше
>
> Персонализированная реклама:  
> ○ Отклонить  
> ○ Принять

Передайте значения, выбранные пользователем, в соответствующие методы. Пример:

- `YG2.optionalPlatform.SetUserConsent(bool consent)` — Передаёт в SDK Yandex Mobile Ads согласие пользователя на сбор персональных данных для аналитики и рекламного таргетинга.
- `YG2.optionalPlatform.SetAgeRestricted(bool ageRestricted)` — Передаёт в SDK Yandex Mobile Ads признак возрастного ограничения пользователя. Если true, сбор персональных данных отключается.

Рекомендуется перевести текст сообщения на язык системы, который установлен у пользователя. Также желательно в настройках приложения дать возможность пользователю поменять выбор о передаче персональных данных и о возрасте.  
Показывать уведомление требуется при первом запуске, при всех последующих требуется только выполнять методы передавая информацию о персональных данных и возрасте пользователя.
