# Доступные платформы

**На данный момент доступны следующие платформы:**

- [Yandex Games](https://max-games.ru/plugin-yg/doc/yandexgames/ "Яндекс Игры")
- [Yandex Mobile ADS](https://max-games.ru/plugin-yg/doc/yandex-mobile-ads/ "Yandex Mobile ADS")
- [CrazyGames](https://max-games.ru/plugin-yg/doc/crazy/ "CrazyGames")
- [Game Distribution](https://max-games.ru/plugin-yg/doc/game-distribution/ "Game Distribution")
- [GameMonetize](https://max-games.ru/plugin-yg/doc/gamemonetize/ "GameMonetize")
- [GamePix](https://max-games.ru/plugin-yg/doc/gamepix/ "GamePix")
- [Y8](https://max-games.ru/plugin-yg/doc/y8/ "Y8")
- [Appodeal](https://max-games.ru/plugin-yg/doc/appodeal/ "Appodeal")
- [Welwise Games](https://max-games.ru/plugin-yg/doc/welwise/ "Welwise Games")

**Plugin Your Games 2.0** — мультиплатформенный. Что это значит❓

- ✔️ Вы можете легко публиковать игры на все самые известные площадки используя единый API от PluginYG. Например — метод для показа рекламы будет один и тот же для всех площадок. В том числе для Google Play.
- 📱 Для мобильных приложений вы можете использовать различные рекламные сети. Мы приготовили для вас готовые модули некоторых рекламных медиаций. PluginYG работает как с WebGL, так и с Android/IOS.
- ⚡️ Переключение между платформами (модулями площадок) производится в один клик и проект настраивается под выбранную платформу. После этого можно делать сборку игры. Плагин не заменяет стандартный процесс сборки и не корректирует какую-либо стандартную логику Unity.
- ⚙️ Для сборки под конкретную платформу устанавливаются соответствующие настройки проекта. Всё гибко настраивается, можно создавать свои опции, которые будут вносить изменения в настройки проекта. Или опции, которые меняются в зависимости от выбранной платформы в проекте, чтобы в коде получать разные значения для разных платформ.
- ➕ Если вам не хватит готовых модулей платформ, плагин предоставляет инструменты для [создания своего собственного модуля](/create-platform/ "создать свой собственный модуль"). С этим справится программист среднего уровня. Если вы умеете интегрировать сторонний SDK платформы в свою игру, то создать модуль для PluginYG у вас тоже получится.

💸 Бесплатно предоставляется сам **Plugin Your Games** и модуль площадки [Яндекс Игры](https://max-games.ru/plugin-yg/doc/yandexgames/ "YandexGames"). Остальные готовые модули платформ вы сможете получить на [Boosty](https://boosty.to/maximalist).
